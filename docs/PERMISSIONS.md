# macOS 权限原理与配置

这篇回答一个问题:**为什么把 DeepSeek Harness 封装成原生 App,比在浏览器里用 WebUI 更强?**

## 1. macOS 的权限模型(TCC)

macOS 用 **TCC(Transparency, Consent, and Control)** 管理系统级隐私权限:

- **受保护资源**:桌面/文档/下载文件夹、照片、通讯录、摄像头、麦克风、全磁盘访问等。
- **授权对象是"应用"**:权限授予给一个具体的 `.app`(按 bundle id 识别),或者给命令行工具(按可执行文件路径)。
- **关键机制——进程树继承**:当一个 App 获得某项权限后,**它启动的所有子进程都自动继承**该权限。App → 子进程 → 孙进程,一路继承。

## 2. 浏览器为什么受限

浏览器(Safari/Chrome 等)是**面向所有网站的共享运行时**,安全模型天然是"每个网站都不可信":

- 网页代码运行在**沙箱渲染进程**里,和浏览器主体隔离;
- 浏览器**永远不会把"全磁盘访问"这类系统权限授予任何网站**——那是操作系统层面的授权,浏览器没有权限转授;
- 你在浏览器里点"选择文件夹",拿到的是**文件句柄级别的临时授权**,刷新页面就可能失效,也无法覆盖"在终端里跑 shell 命令"这种场景。

所以 Harness 的 WebUI 在浏览器里**无法**直接读写桌面/文档、跑需要全磁盘权限的命令。

## 3. 原生 App 为什么可以

本项目的架构是:

```
DeepSeek Harness.app (原生进程,由你显式启动)
  └─ Electron 主进程
       └─ spawn → dsh web 子进程 (Node)
            └─ spawn → bash / 任意 shell 命令
```

**整条链是同一个原生 App 的进程树。** 因此:

1. 你在「系统设置 → 隐私与安全性」里给 **DeepSeek Harness** 授予权限;
2. 权限沿进程树自动继承到 dsh 服务和它跑的每一条 shell 命令;
3. Harness 里的 agent 就可以读写桌面/文档、操作任意本地文件——和你自己在终端里跑命令拥有同等权限。

这是浏览器方案在架构上做不到的,也是本项目存在的意义。

## 4. 如何配置权限

### 4.1 完全磁盘访问(推荐,权限最大)

系统设置 → 隐私与安全性 → **完全磁盘访问权限** → 点「+」→ 添加应用:

- **打包后**:选 `dist/DeepSeek Harness.app`
- **开发模式**(`npm start`):选 Electron 二进制:
  `node_modules/electron/dist/Electron.app`(开发模式下权限属于 Electron 本体)

添加后**重启 App** 生效。

> 注意:完全磁盘访问权限很大,包含你的所有私人文件。**只在本机、只给可信应用授予**。如果只想给某个文件夹(比如 `~/Documents`),用 4.2 的方式更克制。

### 4.2 只给特定文件夹

系统设置 → 隐私与安全性 → **文件与文件夹** → 给 App 勾选「桌面文件夹」「文稿」「下载」等。

### 4.3 首次启动的弹窗

App 内 dsh 第一次尝试访问受保护目录时,macOS 会弹「DeepSeek Harness 想要访问…」,点「允许」即可。如果误点了「不允许」,去系统设置里补授权。

## 5. 安全建议

- **权限与信任绑定**:给 App 授权 = 信任 App 内的 agent 能读写你的文件。请只在可信环境使用,注意 Harness 会话里的指令。
- **最小化原则**:能只给文件夹就不给全磁盘;不用时退出 App(⌘Q)。
- **不要用 sudo**:本项目不需要管理员权限;用 sudo 反而会让 agent 的命令拥有系统级破坏力。
- **日志会记录路径**:dsh 的会话日志(`~/.dsh/sessions/`)包含文件路径,注意别把敏感会话发给别人。

## 6. 后续(打包发布时)

目前 `hardenedRuntime: false`(开发期)。正式发布需要:

1. Apple Developer 账号 + 证书签名;
2. 开启 hardened runtime + entitlements(注意:App Sandbox 会限制进程派生,本方案**不能开 App Sandbox**,否则无法 spawn shell);
3. notarization 公证后分发。

届时权限配置不变,只是「添加应用」时选正式签名的 App 即可。
